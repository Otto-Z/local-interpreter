## 原版 macOS（Python + Swift 壳）说明

> **Android 平板版**详细文档见 [`android/README.md`](android/README.md)。

一个真正的 macOS 应用：不在浏览器里打开，双击即用。麦克风或电脑里正在播放的声音 → 本地 Whisper 识别 → 本地大模型流式翻译 → 实时字幕。全部在本机完成，不联网、不上传。

## 使用

1. 打开 `dist/本地同传.app`（可以拖进「应用程序」文件夹）。
2. **翻译方式默认是「内置模型」**：应用自带 Hy-MT2-1.8B-4bit，无需启动任何其他服务。
   如果想用 oMLX/其它本地服务，到「设置 → 翻译方式」切到「本地服务 / API」，再点「自动检测」填入地址、模型和 Key。
3. 选择音频来源：
   - **麦克风**：面对面说话、开会时用。首次使用会请求麦克风权限。
   - **系统音频**：翻译电脑里播放的视频、网课、会议。首次使用会请求「屏幕与系统音频录制」权限，需要到「系统设置 → 隐私与安全性」里允许。
4. 点「开始」。说话后约 0.5–2 秒出现原文和译文。
5. 「字幕模式」：全屏大字幕，适合放在视频上方看。`Esc` 退出。
6. 「浮字幕」：把字幕放到一个**置顶悬浮窗**里，浮在所有应用和全屏视频上方，可拖动；字号和背景不透明度跟随设置，下次启动自动恢复。快捷键 `⌘⇧F`。
7. 「导出字幕」：把本次内容导出为 SRT 字幕文件。

常用快捷键：`⌘⇧F` 悬浮字幕、`⌘⇧S` 全屏字幕模式、`⌘⇧B` 标记当前句、`⌘⇧Return` 开始/停止。

上课中途需要休息时点「暂停」：停止采集并把当前半句收尾，课次不会结束；点「继续」接着同一堂课记录。

所有权限被拒绝时，界面会提示去哪里开启，不会静默失败。

## 翻译模型

应用内置 **Hy-MT2-1.8B-4bit**（MLX 量化，约 1GB），随应用分发，完全离线；启动时自动加载到内存。
设置 → 翻译方式可以在两种模式间切换：

- **内置模型**：不需要 oMLX 或任何服务，开箱即用。实测首字约 60–250ms，整句约 0.3 秒。
- **本地服务 / API**：任何 OpenAI 兼容接口（oMLX、LM Studio、vLLM、Ollama 等）。

API 模式只依赖最小公共子集：

```
GET  {base_url}/models
POST {base_url}/chat/completions   （SSE 流式）
```

- oMLX 默认地址：`http://127.0.0.1:8000/v1`，通常需要 API Key（在 oMLX 的「服务器」设置里查看）。
- 模型由你自己在 oMLX 里下载加载，应用不预设模型名。

## 课堂助教（右侧栏）

开始一次会话后，顶栏点「助教」打开右侧栏（也可在设置里关闭）：

- **本场要点**：每 60 秒（且至少有 3 句新内容）生成 3–5 条中文要点和当前主题，只在翻译空闲时更新。
- **提问作答**：自动识别课堂中的提问（问号、疑问词），生成中文答案 + 英文对照，标注来源（课堂内容 / 模型知识 / 综合）。同一问题 2 分钟内只答一次。
- **手动提问**：侧栏底部输入框，回车即可针对当前课堂内容提问。
- **助教模型**：应用内置 **Qwen3-4B-Instruct-2507（4bit，约 2.3GB）**，与翻译模型完全独立，不会占用翻译的模型锁；也可以在设置 → 分析模型里改用 oMLX 等外部服务。
- **课程范围**：当前课次属于哪个课程，就只在该课程的讲义、往次课次摘要和本课字幕里找依据。

## 速度与校正

全链路做了这些优化：音频包 32ms（原来 128ms）、句尾判定前 150ms 先跑一次预识别、识别与翻译解耦（下一句识别不必等上一句译完）、正式译文优先于草稿。

- **实测**（SenseVoice + 内置翻译）：识别完成 → 译文首字 0.05–0.1 秒；说完 → 正式译文约 0.3–0.4 秒；草稿在说话过程中已出现。
- **引擎取舍**：SenseVoice 跑在 CPU，延迟最低；Qwen3-ASR 更准，但和内置翻译共用 GPU，连续说话时会多等 0.3–0.5 秒。追求速度选 SenseVoice，追求准确选 Qwen3。
- **字幕显示模式**（设置里可切换）：
  - **整句（默认）**：每句翻译完整，质量最好；草稿在句尾淡入替换。
  - **流式追加（实验）**：只提交两次翻译都一致的“稳定前缀”，剩下的部分显示为灰色临时文本；句子结束时用完整正式译文收尾，草稿和正式译文有偏差时会校正一次，保证字幕不残缺。适合长时间连续说话，读起来像同传打字。
- **边说边译**：说话过程中先出灰色草稿，句尾立即顶上正式字幕位置，正式译文随后替换。
- **停顿判定**：300–400ms 比较跟手；调得太低会把一句话切成几段。
- **快速配方**：SenseVoice + 停顿 300ms + 边说边译 + 内置翻译模型。
- **上下文校正**：识别文本会再用本地模型按上下文做一次同音字校正，只接受“拼音相同、字数相同”的修改；校正后的原文带虚线下划线，点一下可切回原始识别。设置里可关闭。

## 识别引擎

设置 → 识别引擎，三种完全离线的方案：

| 引擎 | 16 秒音频耗时 | 中文准确率（含 10dB 噪声） | 标点 | 说明 |
| --- | --- | --- | --- | --- |
| **Qwen3-ASR-0.6B**（推荐） | 约 0.3 秒 | 噪声下全对 | 有 | 52 语言 + 22 种中文方言，约 1GB |
| **Qwen3-ASR-1.7B** | 约 0.7–0.9 秒 | 两句全对 | 有 | 更准，约 2.5GB |
| SenseVoice-Small | 约 0.2 秒 | 少量错字（“大会议事”） | 有 | 最快之一，约 155MB |
| Whisper large-v3-turbo | 0.7–2.0 秒 | 全对 | 少 | 多语种兜底 |

- 首次切换会自动下载模型；Qwen3 模型缓存在 `~/.cache/huggingface`，SenseVoice 在应用数据目录。
- Qwen3-ASR 支持热词与上下文提示，后续可用于课堂术语。
- 实测为 16 秒中文 TTS + 白噪声，真实课堂建议用 Qwen3-ASR-0.6B（平衡）或 1.7B（准确优先）。
- 另外评测过但未接入：Fun-ASR-Nano 的 MLX 移植会截断文本；FireRedASR2 准确但慢 4–5 倍且无标点；Nemotron 3.5 Transcribe 30B 体积过大。

## 工作原理

```
麦克风 / 系统声音
   │ 原生采集：AVFoundation（麦克风）、ScreenCaptureKit（系统声音）
   │ 统一转换为 16kHz 单声道 PCM
   ▼
Swift 原生外壳 ──WebSocket──▶ 本地 Python 引擎
                                │
                     Silero VAD 分句（按停顿切句）
                                │
                     MLX Whisper large-v3-turbo
                                │
             本地大模型流式翻译（任意 OpenAI 兼容接口）
                                │
                    WebSocket 事件 → 原生界面字幕
```

界面由内嵌的 WKWebView 渲染，但它运行在应用自己的窗口里：没有地址栏、没有标签页，也不依赖 Chrome。

## 识别准确率

- **底部栏的「识别」**：可以手动锁定语言。选「中文」会完全跳过自动检测，中文场景最稳；自动模式会检测一次并沿用 4 句，之后重新检测，适合中英混说。
- **更换识别模型**：设置 → Whisper 模型。`large-v3` 比 turbo 更准但更慢；turbo-q4 最快、精度略降。
- **拾音**：麦克风离嘴越近越好；如果翻译的是电脑播放的声音，优先用「系统音频」，音质远好于外放再被麦克风拾取。
- **背景声**：应用已开启系统级降噪与自动增益；持续的音乐、键盘声仍可能被识别成文字。
- **中英混说**：语言锁定会每 4 句重新检测一次；切换语言后如果译文方向不对，把底部「识别」改成对应语言即可。

## 排查

- **翻译需要 API Key**：oMLX 等服务默认要求 Key。设置里点「读取 oMLX Key」，或手动填写。
- **翻译服务未连接**：确认 oMLX 等服务已启动，地址端口正确（oMLX 默认 8000）。
- **测试连接很慢**：第一次请求会触发模型加载，之后再测通常会快很多。
- **没有麦克风声音**：系统设置 → 隐私与安全性 → 麦克风，允许「本地同传」。
- **没有系统声音**：系统设置 → 隐私与安全性 → 屏幕与系统音频录制，允许「本地同传」，然后重启应用。
- **应用启动失败**：查看 `~/Library/Application Support/本地同传/app.log` 与 `native.log`。
- **退出应用**：界面「设置 → 退出应用」，或按 ⌘Q。

## 课程与课次

顶栏「课程」按 **课程 → 课次** 组织所有记录：

- 新建 / 重命名 / 删除课程；删除课程时，课次和资料会移到「未分类」。
- 课程详情：课程笔记、课程资料（讲义）、课次列表（可搜索标题/摘要）。
- 每个课次：自动标题、主题标签、摘要、双语字幕、问题与答案、说话人、逐句音频回放；可写本课笔记、导出 SRT / Markdown。
- 直播时底栏「课程」下拉选择本课归属；助教答题会自动带入所属课程的讲义和往次课次摘要。
- 数据保存在 `~/Library/Application Support/本地同传/history.db`，音频在同目录 `audio/` 下。

## 课程资料

在课程详情页上传 PDF / DOCX / PPTX / TXT / Markdown 讲义，资料归到该课程下。助教回答问题时按「课堂内容 → 课件 → 模型知识」的顺序取材，引用课件时会标注页码。扫描版 PDF 没有文字层时，会自动调用随应用附带的 macOS Vision OCR（完全离线，支持中英文）。

## 术语表与课程问答

- **术语表**：课程详情页可手动添加术语/译名，或点「AI 自动提取」从讲义和课堂记录里生成 8–15 个专业术语。术语会自动用于该课程的语音识别热词和翻译提示，保持人名、产品名、专业词前后一致。
- **问这门课**：课程详情页顶部输入问题，会在**所有课次的原话 + 往次摘要 + 课程资料 + 术语表**里检索，再由助教模型回答，并列出依据（资料页码 / 课次日期）。支持连续追问，会带上最近几轮对话。
- **搜索课堂原话**：课程页的搜索框除了过滤课次标题，也会检索所有课次的字幕，点结果直接跳到对应课次。
- **自动术语**：下课后会自动补充本课出现的新术语（可在设置里关闭）。
- **课前预习**：根据课程资料生成 4–6 条本节要点和 3 个听课问题，保存到课程里。
- **课后复习**：每个课次可生成 5 道复习题，支持导出 Anki（TSV）；课中底栏「标记」会记下当前句，课后在书签里点 ▶ 直接回听。

字幕会按文本长度、重复字符、标点等信号标出低置信度句子（原文变暗/黄线），历史里也保留这个标记；它不是模型概率，只用于提示“这句可能识别得不太稳”。

## 存储、隐私与评测

- 所有数据都在本机 `~/Library/Application Support/本地同传/`，目录权限 700、数据库 600，不上传云端。
- 设置 → 存储与隐私：查看数据库/录音/资料/模型占用和磁盘剩余；可设置「自动清理 N 天前的课次」（0 为永久保留），或手动按设置清理。
- 设置 → 翻译评测：空闲时用固定例句测当前翻译链路的首字延迟、整句耗时和完整性。正在上课时会拒绝运行，避免抢占模型。
- 设置 → 模型管理：查看翻译/助教/识别模型状态；轻量版可在这里按需下载助教模型（约 2.3GB，下载后完全离线）。

## 轻量安装包


轻量包保留内置翻译模型和全部翻译/课程功能；首次使用助教总结、答题或术语提取时，在设置 → 模型管理里下载助教模型即可。完整包约 4.6GB，轻量包约 2.3GB。

## 说话人区分

本地 CAM++ 声纹模型（约 27MB，随应用提供）对每段音频做嵌入和在线聚类，字幕会标出「说话人 1 / 2…」，历史详情里可重命名成「老师」「同学 A」。两人交替说话的场景实测可正确区分；多人抢话或音色接近时可能出错，可在设置里关闭。
